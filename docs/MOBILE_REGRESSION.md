# 真机回归基线

## 目标与设备矩阵

每次涉及地图层级、详情返回、筛选、滚动、发布表单或移动端尺寸时，至少覆盖以下环境。自动化脚本只验证纯状态逻辑，不能替代真机触控与 WebView 检查。

| 环境 | 视口与显示设置 | 重点 |
| --- | --- | --- |
| 一加 12 · Chrome | 系统字体标准/大号各一次，Chrome 页面缩放 100% | 字体自动放大、底部安全区、拖拽与返回 |
| 一加 12 · 微信内置浏览器 | 系统字体标准 | WebView 尺寸、返回栈、上传与图片预览 |
| iPhone Safari | 默认字体，竖屏 | safe-area、地址栏伸缩、视觉视口与键盘 |
| 桌面 Chrome 移动模拟 | 390×844 与 412×915 | 快速布局和控制台冒烟，不作为真机通过依据 |

## 运行前

1. 启动 `npm run dev`，使用同一局域网地址打开应用；不要用 `localhost` 代替手机访问地址。
2. 清空当前标签页的 sessionStorage，完成一轮冷启动；再保留 sessionStorage 完成一轮恢复测试。
3. 记录设备、浏览器版本、系统字体、页面缩放、分支和 commit；失败时保存截图、录屏、控制台与复现步骤。

## 核心用例

### A. 地图首屏与界面互斥

- 首次进入可出现一次“附近活动”；收起并切换页面再返回时保持收起。
- 地图点位弹窗、附近活动、发布菜单、发布表单、路线和线路面板任意时刻只出现一个主界面。
- 主界面打开时，顶部筛选/天气/地图控件及底部工具向四周退避；发布菜单打开时工具栏从菜单下层退出，不产生瞬间遮挡。
- 拖动、缩放和点击空白地图不展开推荐；锚点本身可保留，点击锚点或胶囊才展开。

### B. 推荐排序与解释

- 默认结果优先显示正在进行、今天可去、距离较近或即将结束的活动。
- 切换“放松/一个人/拍照/夜生活”后顺序变化合理，卡片显示最多两条对应原因，且距离与场地仍可读。
- 同一数据和场景反复打开时顺序稳定；无时间、无图片、无场地的活动仍可打开，不出现 `NaN` 或空白标签。

### C. 跨页面恢复与返回

- 地图移动到明显位置并改变缩放，进入活动详情后关闭：回到原地图中心与缩放，附近活动保持收起。
- 探索页设置标签、分类、日期、搜索词并滚动，切到日历或地图后返回：筛选与滚动位置恢复。
- 日历页切换月份、日期、活动状态和分类，打开/关闭详情并切换页面返回：选择与滚动位置恢复。
- 保留标签页刷新一次：UI 状态恢复；新开标签页：不继承旧标签页状态；切换账号：账号范围内的探索状态不串用。
- 从地图活动进入详情后关闭回地图；从探索/日历打开详情后关闭仍留在原页面，不额外跳转。

### D. 移动端高风险交互

- 发布/编辑动态、活动、足迹：上传多图后长按拖动，只换位一次且不抖动；轻点可全屏预览；键盘弹出后底部操作仍可见。
- 活动时间起止都可选日期和时间；提交 loading 位于视口中央，成功提示不被附近活动或底部导航遮挡。
- 官方活动详情的“想去/路线/AI 导游”尺寸正常；“想去”立即反馈，AI 导游有历史记录时仍显示入口问候与备选项。

## 通过标准

- 无重叠主界面、点击穿透、不可关闭遮罩、返回错页、状态串号、布局横向溢出或持续抖动。
- Chrome 与微信的关键字号、按钮和间距没有显著尺度跳变；系统大号字体下允许内容增高，但不允许裁切主要操作。
- 控制台无新增错误，关键请求无意外重复或失败；自动回归命令 `npm run test:regression`、TypeScript 和生产构建通过。
